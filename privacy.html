プライバシーポリシー

Academic Scheduler

1. 基本方針

Academic Scheduler（以下「本ツール」）は、開発者本人が研究スケジュールを管理するために 利用する個人用ツールです。本ツールは、利用者本人の Google カレンダーの情報を、 計画の作成という目的のためだけに利用します。

2. 取得する情報

本ツールは Google カレンダー API を通じて、次の情報を読み取ります。

情報カレンダーの予定の開始時刻・終了時刻・終日かどうか・件名・所属カレンダー名
スコープhttps://www.googleapis.com/auth/calendar.readonly（読み取り専用）
範囲実行時点から概ね90日先までの予定

読み取り専用のため、本ツールが予定を作成・変更・削除することはありません。

3. 利用目的

  • 日ごとに研究へ充てられる時間の割合（稼働）を算出するため
  • 締切までの残り時間を見積もり、作業計画の案を作るため
  • 計画を図（ガントチャート）として表示するため

これ以外の目的には利用しません。広告配信や行動分析には一切利用しません。

4. 情報の保存場所

取得した予定の内容は、利用者本人の端末（Mac）の中だけで処理されます。 本ツールは外部の解析サービスや広告ネットワークに情報を送信しません。

アクセストークン本人の端末内のファイルにのみ保存されます（~/.config/google-calendar-mcp/tokens.json 等）
予定の内容計算のために一時的にメモリ上で扱うだけで、保存も外部送信も行いません

算出結果の取り扱いについて。 本ツールは計算結果として、日付ごとの稼働の数値（例：2026-11-07 / 0.7 / 午前のみ空き）を、 開発者本人が所有する非公開のリポジトリに保存します。 ここに保存されるのは空き具合を表す数値と中立的な区分だけであり、 予定の件名・場所・参加者といった内容は含まれません。 これは、予定に関係者を特定しうる情報が含まれうることを踏まえた、意図的な設計です。

5. 第三者への提供

取得した情報を第三者に販売・譲渡・開示することはありません。 法令に基づく開示請求があった場合を除き、外部に提供しません。

6. Google ユーザーデータの取り扱い

本ツールによる Google ユーザーデータの利用は、 Google API Services User Data Policy （限定利用要件を含む）に従います。

7. アクセスの取り消しとデータの削除

利用者はいつでも、次の方法で本ツールのアクセスを取り消せます。

  • Google アカウントのサードパーティ接続の画面から、本ツールのアクセス権を削除する
  • 端末内に保存されたトークンファイルを削除する

アクセスを取り消すと、本ツールはカレンダーを読み取れなくなります。 端末内にはカレンダーの内容が保存されていないため、トークンファイルの削除をもって Google から取得した情報は残らない状態になります。
